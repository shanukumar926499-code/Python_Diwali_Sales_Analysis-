# Diwali Sales Analysis

A beginner-friendly Python project that explores Diwali sales data to understand customer purchasing behavior and identify opportunities to improve sales and customer experience.

## Project objectives

- Clean and explore the sales dataset.
- Analyze customer demographics and purchasing patterns.
- Identify high-performing product categories and customer segments.
- Present insights using visualizations.

## Project structure

```text
Python_Diwali_Sales_Analysis/
├── Diwali Sales Data.csv
├── Diwali_Sales_Analysis.ipynb
└── README.md
```

## Tools and libraries

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/shanukumar926499-code/Python_Diwali_Sales_Analysis.git
   cd Python_Diwali_Sales_Analysis
   ```

2. Install the dependencies:

   ```bash
   pip install jupyter pandas matplotlib seaborn
   ```

3. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open `Diwali_Sales_Analysis.ipynb` and run the cells in order.

## Analysis

The notebook explores the dataset through data cleaning, descriptive statistics, and visualizations. It can help identify patterns in customer demographics, product preferences, and sales performance.
